# Interview Metric Reasoning Lab

Six original numeric-evidence exercises with fictional datasets, explicit definitions, paper worksheets, hand calculations, reasoned answer keys and follow-up questions. Open index.html locally or serve these static files. No code is needed to work through the exercises.

All organizations, people, data and results are fictional. Do not present these examples as your work history. No professional hiring expertise, validated scores or outcomes are claimed. AI-assisted educational drafting; published by MakeInterview / MockLive. The separate live AI interview service is currently paused. This manual lab works independently.

Planned site: https://szj2ys.github.io/interview-metric-reasoning-lab/

## Printing and offline use

Open a case and use Print. The worksheet begins on its own page; keep the later answer key aside until you finish. Keep style.css beside the HTML files when saving them locally. There are no runtime scripts, external dependencies, forms, accounts, analytics or saved answers. Use paper or your own notes for calculations.
